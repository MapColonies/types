Simplified Basemap Types

The basemap model in @map-colonies/types after simplification. The write model is now the only place fields are declared. The read model no longer repeats them: each read type extends its write counterpart and swaps one field, and a read source is just a write source plus its resolution status. Runtime schemas for the read model come from three factories that take the caller's layer and capabilities schemas.
